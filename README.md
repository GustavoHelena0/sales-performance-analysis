# Análise de Vendas | Dashboard Interativo (Looker Studio)

Projeto de análise de vendas utilizando Looker Studio, com foco na identificação de tendências, padrões regionais e fatores que impactam o desempenho comercial.

## Visualize o Dashboard

👉 https://datastudio.google.com/reporting/beb1907b-e9df-49ab-a379-afe964770138

## Funcionalidades

- Dashboard interativo no Looker Studio
- Análise temporal das vendas
- Segmentação por estado, categoria e produto
- Visualização de métricas de negócio
- Identificação de padrões e sazonalidades
- Investigação de possíveis gargalos operacionais

## Principais Métricas

- Receita total
- Volume de vendas
- Ticket médio
- Vendas por estado
- Vendas por categoria

## Principais Insights

- A **Bahia (BA)** concentra o maior volume de vendas
- A categoria **Alimentos** lidera o faturamento
- Fevereiro apresentou pico de vendas no período analisado
- Junho apresenta valores menores por conter dados ainda incompletos
- Existem indícios de sazonalidade no desempenho mensal

## Como Usar

1. Acesse o dashboard pelo link:

```txt
https://datastudio.google.com/reporting/beb1907b-e9df-49ab-a379-afe964770138
```

2. Utilize os filtros interativos para explorar:

- Estados
- Categorias
- Produtos
- Períodos de venda

3. Analise os indicadores e gráficos disponíveis no dashboard.

## Ferramentas Utilizadas

- Google Looker Studio
- SQL
- Excel

## Qualidade dos Dados

Durante a análise, foram considerados desafios comuns em dados reais:

- Inconsistências de formatação numérica
- Valores ausentes
- Dados parciais em períodos recentes
